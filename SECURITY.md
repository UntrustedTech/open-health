# Security Policy

Health keeps sensitive health data on the user's phone, so we take security
reports seriously.

## Reporting a vulnerability

Please **don't** open a public issue. Email **support@untrustedtech.dev** with
the subject "Security", including:

- what the problem is and what an attacker could do with it;
- steps to reproduce it, and the app version (Settings → About → Version);
- any proof of concept, and how you'd like to be credited (if at all).

We'll acknowledge your report within 7 days, keep you updated, and aim to
release a fix within 90 days, after which you're welcome to publish your
findings. Please give us that time before disclosing it publicly, and
don't access other people's data, or harm users, while testing.

## Supported versions

Only the latest release gets security fixes.

## No bounty

Health is a small, independent project and doesn't offer paid rewards, but
we're happy to credit you in the release notes.
