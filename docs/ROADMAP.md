# Roadmap

What's out, what's being worked on, and what comes after. Plans can change;
updates come from what people ask for, so suggest something in
[Issues](https://github.com/UntrustedTech/open-health/issues) or at
support@untrustedtech.dev.

## Out now

- [x] **Open Health 1.0.0 for Android** on
  [GitHub Releases](https://github.com/UntrustedTech/open-health/releases/latest),
  with a daily check for new versions.

## Next

- [ ] **Google Play.** Coming soon. Want to test it there before it
  launches? Email **support@untrustedtech.dev** to join the beta.
- [ ] **iPhone build on GitHub Releases.**

## Later

- [ ] **App Store.**
- [ ] **Plugin support:** small add-ons that bring new features, such as
  reading a watch or sensor directly, each running sandboxed with only the
  permissions you allow.
- [ ] **Themes and app icons:** extra styles for the whole app, a theme
  editor and more Home Screen icons.
